description: >-
  MetaWhat is a variable bilingual typeface. It is inspired by the idea that the
  metaverse is an internet that is accessed using the physical sense of space,
  and that the metaverse allows for shapeshifting. Available with Latin and
  Arabic alphabets, this variable typeface is scalable in weight and form. This
  project was designed with Khajag Apelian for Studio Sharaf.


  This typeface won a Certificate of Typographic Excellence from the Type
  Directors Club NYC.
